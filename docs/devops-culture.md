# DevOps Culture and CALMS

| CALMS dimension | TaskFlow evidence |
|---|---|
| Culture | PR template, ownership, review and incident-oriented runbooks |
| Automation | GitHub Actions, Docker, Terraform, Ansible and Helm |
| Lean | Small independently deployable frontend/backend services and reproducible environments |
| Measurement | Prometheus metrics, Grafana, SLIs, SLOs and error-budget concepts |
| Sharing | README, architecture, troubleshooting and interview documentation |

The capstone demonstrates the practices through automation and operational evidence rather than treating CALMS as a slide-only topic.
